# 🇸🇦 مكتبة `f_ksa` — أدوات البيانات السعودية والعربية الذكية

مكتبة بايثون خفيفة، سريعة، ومبسطة مصممة لتسهيل التعامل مع البيانات المحلية في المملكة العربية السعودية وتنظيف النصوص العربية بسطر واحد فقط، مع رسائل تفاعلية ذكية ومخصصة باللهجة السعودية.

* **المطوّرة:** Fida (`@fdoxsy`)
* **الإصدار الذهبي:** `1.0.0`
* **المستودع الرسمي:** [PyPI - f_ksa](https://pypi.org)

---

## ⚡ طريقة التثبيت

### التثبيت الرسمي من مستودع بايثون (PyPI):
    pip install f_ksa

### أو التثبيت المباشر من GitHub:
    pip install git+https://github.com

## 🛠️ الأدوات المتوفرة (15 أداة متكاملة)

| الدالة | الوظيفة |
| :--- | :--- |
| `normalize_numbers()` | تحويل الأرقام العربية/الهندية (`٠١٢٣`) إلى إنجليزية (`0123`) |
| `fix_phone()` | تنسيق أرقام الجوال السعودية للصيغة الدولية الموحدة (`9665xxxxxxxx`) |
| `clean_text()` | إزالة التشكيل والرموز وتوحيد الهمزات والتاء المربوطة |
| `check_iban()` | فحص الآيبان السعودي وتحديد اسم البنك تلقائياً |
| `check_saudi_id()` | فحص صحة رقم الهوية الوطنية أو الإقامة بالخوارزمية الرياضية الرسمية |
| `calc_vat()` | حساب ضريبة القيمة المضافة السعودية (15%) أو استخراجها من مبلغ شامل |
| `get_region()` | تحديد المنطقة الإدارية لأي مدينة سعودية |
| `calc_zakat()` | حساب زكاة المال الشرعية (`2.5%`) والمبلغ المتبقي |
| `tafkeet()` | تحويل الأرقام إلى كتابة عربية رسمية للفواتير بالريال السعودي |
| `extract_data()` | استخراج أرقام الجوال والآيبان تلقائياً من أي نص فوضوي |
| `arabic_date()` | تحويل التاريخ إلى صيغة عربية كاملة مع اسم اليوم والشهر |
| `convert_sar()` | تحويل العملات من الريال السعودي إلى (USD, EUR, AED, KWD, GBP) والعكس |
| `calc_age()` | حساب العمر الدقيق بالسنوات والأشهر والأيام |
| `check_password()` | فحص قوة كلمة المرور وإعطاء نصائح ذكية لتقويتها |
| `saudi_holidays()` | عرض المناسبات الوطنية الرسمية في المملكة العربية السعودية |

## 💻 أمثلة سريعة للاستخدام

    import f_ksa as fk

    # توحيد رقم الجوال (يدعم تخصيص الخطاب: gender="f" للأنثى، gender="m" للذكر)
    print(fk.fix_phone("050-123-4567"))

    # تفقيط المبالغ للفواتير
    print(fk.tafkeet(1250))

    # فحص الآيبان ومعرفة البنك
    print(fk.check_iban("SA0380000000608010167519"))

    # حساب ضريبة القيمة المضافة 15%
    print(fk.calc_vat(100))

    # استخراج البيانات من نص فوضوي
    print(fk.extract_data("رقمي 0551112222 وايباني SA0380000000608010167519"))
